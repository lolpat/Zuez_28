# limitless-promo

PROMPT 10 from the Motion Graphics starter kit, run on real Limitless screens instead of the kit's
Tally practice screens: a 60-second, 1920x1080, 30 fps kinetic promo. Cuts land on a 120 BPM grid
(every 0.5 s).

## Sound (PROMPT 13)

Kit sound effects from `assets/sfx/`, placed by `tools/gen_promo.py` so each one's peak lands one frame
after its picture: a tick as each screen's caption line lands (12), a snap on each big word slam (9),
and a chime on the end card. No sound on slides, exits or cuts, no whooshes, no counter (no numbers
roll in this video). Measured on the render: −30.7 LUFS, true peak −11.9 dB, no clipping.

## Files

- `screenshots/` — the 12 original screenshots, untouched. Not committed (they show other members' names
  and photos and an account number); put them back here to change crops.
- `assets/screens/` — what the video uses: the screenshots with the phone status bar and browser bar
  trimmed off, a few tighter crops, the leaderboard with member names and photos blurred, and the
  Limitless wordmark cropped from the dashboard.
- `compositions/*.html` — one file per scene, generated by `tools/gen_promo.py` (shot list, copy and
  timing all live at the top of that script). Edit the script and run `python3 tools/gen_promo.py .`,
  or edit a scene file directly.
- Fonts: Inter and Archivo Black from the kit (SIL OFL). GSAP 3.14.2 is in `assets/vendor/`.

Left out on purpose: the MT5 account number, other members' names and photos, the performance and
"World's #1 / 500,000+ traders" claims, the Sonic artwork and the brand-name XP prizes.

## Render

```bash
# In a Claude Code cloud container, point HyperFrames at the preinstalled headless Chromium:
export HYPERFRAMES_BROWSER_PATH=/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell
npx hyperframes check
npx hyperframes render . --fps 30 -o renders/promo.mp4
```
