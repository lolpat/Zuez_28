# OTM hashtag playbook (Instagram + TikTok)

Researched November 2026. Post counts come from third-party hashtag sites (they disagree and some data is old), so
treat them as rough sizes and re-check in the apps' own search before a big campaign.

## The rules

**Instagram:** at most **5** hashtags (several sources report a 5-tag cap since December 2025; 5 is safe either way).
Hashtags in the first comment count toward the same cap. Reels are pushed by interest signals, so the hook and caption
matter as much as the tags.

**TikTok:** **3–5** hashtags, plus a plain-words keyword phrase at the start of the caption (TikTok search reads the
caption; keyword stuffing can be treated as spam).

**Formula (both platforms):** 1 big + 1–2 mid + 1–2 niche for the video's topic + the brand tag.

| Size | Tags (approx. size) |
|---|---|
| Big | #forex (~11.7M all platforms, ~2.3M TikTok), #trading (~7.1M all, ~8.4M TikTok) |
| Mid | #forextrading (~3.8M Instagram, ~824K TikTok), #forextrader (~5.4M), #daytrading (~1.7M Instagram) |
| Niche (pick by topic) | #forexeducation (~98K TikTok), #tradingpsychology, #riskmanagement, #priceaction, #technicalanalysis, #smartmoneyconcepts (~419K Instagram), #xauusd / #eurusd for pair-specific posts |
| Brand (always) | #OrderTheMarket |

**Avoid:** #forexsignals, #binaryoptions, #forexlifestyle, #money / #wealth flex tags (spammy and a compliance risk for
education content), and #fyp (huge, but no evidence it helps; spend the slot on a niche tag).

## Caption shape

1. Hook line with the keyword in plain words ("Forex trading mindset: start before you're ready").
2. Optional one-line value or call to action ("Save this 📌").
3. Music credit when the track is CC BY.
4. The hashtag set on the last line.
